# Insta Text Studio v2

Minimalist, browser-only Instagram carousel creator.

## Run locally
Open `index.html` in a browser, or run:
```bash
python3 -m http.server 8000
```
Visit http://localhost:8000.

## Publish on GitHub Pages
1. Create a GitHub repository and upload `index.html` and this README.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Save and open the published Pages URL.

## Features
- Generate a carousel from long-form text
- Cover, content and closing slides
- Edit each slide after generation
- Minimal typography and six neutral palettes
- Portrait, square and story formats
- Full-resolution individual PNG exports
- No backend, account, API key or database

"Download all slides" starts separate PNG downloads. Some browsers require you to allow multiple downloads for the site.
